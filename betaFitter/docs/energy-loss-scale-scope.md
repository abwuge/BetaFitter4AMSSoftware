# zeta 作用范围验证结论

## 背景

`BetaNL` 使用 TOF 各层的能量沉积修正粒子传播过程中的能量损失。原始实现将能损缩放因子 zeta 作用于前三个 TOF edep，即 S1、S2、S3；S4 之后没有参与拟合的传播区间，因此 S4 edep 不进入计算。

本次验证考察两种简化：

- `s2`：zeta 仅作用于 S2；S1、S3 edep 仍扣除，但系数固定为 1。
- `s1s2`：zeta 作用于 S1、S2；S3 edep 仍扣除，但系数固定为 1。

原行为记为 `all`。

## 传播模型中的累计能损

实际 Z2 MC 样本中，三个传播区间的中位长度为：

| 区间 | 中位长度 |
|---|---:|
| S1-S2 | 3.18 cm |
| S2-S3 | 127.83 cm |
| S3-S4 | 3.19 cm |

虽然 S1-S2 和 S3-S4 很短，但 S1 与 S3 的作用并不对称。传播采用累计扣能：粒子在 S1 损失的能量会保留到所有后续区间，因此也会影响最长的 S2-S3 区间；S3 的能损则只影响最后约 3 cm 的 S3-S4 区间。

设 S1、S2 的能量沉积分别为 `dE1`、`dE2`，则进入 S2-S3 区间时：

```text
E_all = E0 - zeta_all * (dE1 + dE2)
E_s2  = E0 - dE1 - zeta_s2 * dE2
```

Z2 MC 中 `dE1/dE2` 的中位数为 0.994，二者几乎相等。若要求两种模式在 S2-S3 区间具有相同能量，则：

```text
zeta_s2 = zeta_all + (zeta_all - 1) * dE1 / dE2
```

代入 `zeta_all = 1.9` 和 `dE1/dE2 = 0.994`，得到 `zeta_s2 = 2.79`，与实际重新拟合得到的约 2.8 完全一致。因此，S1 上的 zeta 不能因 S1-S2 距离短而省略。

## 验证样本与方法

分别从 `input_Z2.list`、`input_Z6.list`、`input_Z8.list` 的第一个 MC 文件提取前 10,000 条事件。两种模式始终使用同一个输入样本，并按输出条目逐事件配对比较。

- beta 比较使用固定 `zeta = 1.9`。
- zeta 比较固定 MC beta，逐事件重新拟合 zeta。
- zeta 汇总沿用现有分析选择 `mcBeta < 0.9`。
- 有效 beta 条目数分别为 Z2 9,853、Z6 9,728、Z8 9,666。

验证工具：

- `macro/makeValidationSample.C`：生成固定条目数的同源 MC 子样本。
- `macro/validateZetaScope.C`：检查条目对齐，计算逐事件差值、分位数、分 beta 汇总及 zeta 相关性，并生成比较图。

## 结果一：仅保留 S2 不足以复现原结果

以下差值定义为 `1/beta_s2 - 1/beta_all`：

| Z | 差值中位数 | 95% `abs(diff)` | 全范围残差 RMS：all -> s2 | 最大分 beta 均值差 |
|---|---:|---:|---:|---:|
| 2 | `1.04e-5` | `8.21e-3` | 0.03352 -> 0.03436 | 0.0573 |
| 6 | `8.41e-6` | `7.20e-3` | 0.02717 -> 0.02840 | 0.0530 |
| 8 | `1.03e-5` | `7.08e-3` | 0.01891 -> 0.02032 | 0.0493 |

主体峰在高 beta 区域看起来接近，但低 beta 区域出现明显系统偏移。原因是 `s2` 模式在进入长 S2-S3 区间时少扣了 `(zeta - 1) * dE1`。低 beta 时粒子动能较小，几 MeV 的能量差即可显著改变 beta，因此该差异被明显放大。

逐事件 zeta 也发生系统变化：

| Z | zeta 中位数：all -> s2 | zeta RMS：all -> s2 | 相关系数 |
|---|---:|---:|---:|
| 2 | 1.863 -> 2.769 | 4.838 -> 5.993 | 0.9581 |
| 6 | 1.911 -> 2.854 | 2.572 -> 4.054 | 0.9566 |
| 8 | 1.942 -> 2.904 | 2.135 -> 3.544 | 0.9657 |

`s2` 模式只通过 `dE2` 约束 zeta，而 `all` 模式通过近似同量级的 `dE1 + dE2` 约束 zeta，因此前者灵敏度更低、逐事件分布更宽。

## 结果二：S1 和 S2 足以复现原结果

以下差值定义为 `1/beta_s1s2 - 1/beta_all`：

| Z | 差值中位数 | 95% `abs(diff)` | 99% `abs(diff)` | 残差 RMS：all -> s1s2 |
|---|---:|---:|---:|---:|
| 2 | `1.00e-7` | `1.07e-4` | `6.89e-4` | 0.033520 -> 0.033514 |
| 6 | `5.50e-8` | `9.40e-5` | `6.77e-4` | 0.027173 -> 0.027191 |
| 8 | `3.95e-8` | `8.89e-5` | `7.49e-4` | 0.018906 -> 0.018919 |

逐事件 zeta 基本不变：

| Z | zeta 中位数：all -> s1s2 | zeta RMS：all -> s1s2 | 相关系数 |
|---|---:|---:|---:|
| 2 | 1.863 -> 1.871 | 4.838 -> 4.859 | 0.99948 |
| 6 | 1.911 -> 1.922 | 2.572 -> 2.584 | 0.99980 |
| 8 | 1.942 -> 1.949 | 2.135 -> 2.147 | 0.99987 |

这说明 S3 上的 zeta 对当前 beta 重建和 zeta 拟合均只有很小影响，与 S3-S4 区间很短的几何预期一致。

## 结论与使用建议

1. S1 的能损会累积到长 S2-S3 区间，不能从 zeta 作用范围中去除。
2. S3 的能损只影响很短的 S3-S4 区间，可以不施加 zeta，而不会显著改变当前结果。
3. 若希望简化 zeta 的作用范围，`s1s2` 是经过 Z2、Z6、Z8 同事件验证的可行选择。
4. `all` 仍作为默认值保留，以维持已有任务的行为和结果兼容性。

运行开关：

```bash
# 原行为：zeta 作用于 S1、S2、S3
./run.sh input.root output.root 0 1.9 1.0 all

# 验证支持的简化：zeta 作用于 S1、S2
./run.sh input.root output.root 0 1.9 1.0 s1s2

# 研究模式：zeta 仅作用于 S2
./run.sh input.root output.root 0 1.9 1.0 s2
```
